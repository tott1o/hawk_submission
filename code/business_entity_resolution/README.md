# Business Entity Resolution — Solution Pipeline

This repository contains the complete, self-contained machine learning pipeline for the Amazon ML Challenge 2026.

## System Architecture

The solution uses a two-stage architecture:
1. **Candidate Generation (Blocking)**: Country-Partitioned Multi-Key Inverted Index that extracts sorted name token pairs, salient brand tokens, prefix pairs, and street-number address keys. Cuts the search space from $17.3 \times 10^{12}$ pairs to $< 8$ candidates per entity with $>89\%$ recall.
2. **Entity Matching (ML Model)**: Cost-sensitive Random Forest Classifier trained on real blocking candidate pairs with hard negatives, using 15 RapidFuzz string similarity features and an optimal threshold ($\tau = 0.90$) tuned specifically for the Macro $F_{0.5}$ metric.

## End-to-End Reproduction Guide

### 1. Training the Model
Train the matching model on candidate pairs from the training dataset:
```bash
python src/train.py
```
This fits the inverted index on candidate sources, extracts training pairs with hard negatives, trains the Random Forest classifier, tunes the decision threshold on validation entities, and saves the model to `models/model.pkl`.

### 2. Running Test Inference
Generate predictions for all 1,732,544 test entities:
```bash
python src/predict.py
```
This produces:
- `output/matching_results.tsv` — final matched entity IDs (uploaded to leaderboard).
- `output/candidate_pairs.tsv` — candidate sets generated by blocking.

### 3. Validation
Validate the output format:
```bash
python utils/validate_submission.py \
    --matching output/matching_results.tsv \
    --candidate output/candidate_pairs.tsv \
    --test-dir dataset/test
```
